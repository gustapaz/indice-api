Índice API · GraphQL

POST /api/graphql com Content-Type: application/json. Sem batching, upload ou queries por GET. O schema é público; documentos exigem Authorization: Bearer <token>.

Começar

{
  "query": "mutation { createWorkspace { id token expiresAt } }"
}

O token aparece uma vez. Guarde-o temporariamente, não em URLs ou Git. Não há recuperação por conta ou senha. Use somente dados sintéticos.

Gravar, buscar e atualizar

mutation { createDocument(title:"Guia", body:"Métricas e observabilidade") { id revision } }

query { search(term:"metri",first:5) { edges { cursor node { id title excerpt revision } } pageInfo { endCursor hasNextPage } } }

mutation Update($id:ID!) { updateDocument(id:$id,expectedRevision:1,title:"Guia revisado",body:"Novas métricas") { id revision } }

mutation { revokeWorkspace }

Envie uma operação por requisição; mutações aceitam um campo raiz. Revisão antiga retorna errors com code CONFLICT. Leituras fora do workspace retornam null; mutações retornam NOT_FOUND. GraphQL pode retornar HTTP 200 com errors.

Semântica e limites

20 documentos/workspace; título 1–100 caracteres, corpo até 2000; first 1–10. Cursores base64 de UUID, ordenados por ID, sem promessa de snapshot entre páginas. Busca aceita 1–4 termos de 2–24 letras/números, com prefixo e AND; sem sintaxe FTS arbitrária. Excerpts usam colchetes, não HTML.

Workspace expira em 24 horas. Revogar exclui documentos e índice. Exclusão física dos expirados é oportunística. Cota global: 10 criações/hora UTC; por workspace: 60 escritas/hora. Revogação continua disponível mesmo com a cota de escrita esgotada.

Corpo até 32 KiB, query até 12000 caracteres, profundidade 8, até 100 campos expandidos e 10 aliases/raízes. Introspecção só de schema tem limites maiores e não acessa dados. Sem cartão ou faturamento ativado; disponibilidade depende da hospedagem. Não envie informações sensíveis.

Schema SDL

 "A synthetic document isolated by workspace token."
 type Document { id: ID!, title: String!, body: String!, revision: Int!, updatedAt: String!, excerpt: String }
 type WorkspaceSession { id: ID!, token: String!, expiresAt: String! }
 type PageInfo { endCursor: String, hasNextPage: Boolean! }
 type DocumentEdge { cursor: String!, node: Document! }
 type DocumentConnection { edges: [DocumentEdge!]!, pageInfo: PageInfo! }
 type Query {
   document(id: ID!): Document
   documents(first: Int = 5, after: String): DocumentConnection!
   search(term: String!, first: Int = 5, after: String): DocumentConnection!
 }
 type Mutation {
   createWorkspace: WorkspaceSession!
   revokeWorkspace: Boolean!
   createDocument(title: String!, body: String!): Document!
   updateDocument(id: ID!, expectedRevision: Int!, title: String!, body: String!): Document!
   deleteDocument(id: ID!, expectedRevision: Int!): Boolean!
 }
